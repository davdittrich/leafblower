<objective>
G-03-1 (UAT gap): Phase 3's benchmark scope was narrowed to `oris_soft` vs three generic
survey packages, plus one `raking_accelerated` cross-check on a degenerate fixture. The user
wants EACH of leafblower's methods benchmarked against ITS OWN closest competitor. This plan
covers the five methods (`oris`, `raking`, `newton_kl`, `greg`, `logit`) whose doc-named
closest competitor is `survey::calibrate` — already an installed dependency (`Suggests:` in
`DESCRIPTION`) — so no new package is required. `greenkhorn`/`sinkhorn` (POT, cross-language)
and `chebyshev` (optweight, new R package) are out of this plan's scope — see 03-07-PLAN.md
and 03-06-PLAN.md respectively.

Research this session (cited inline in each task) confirmed the exact competitor mapping by
reading all eight `docs/methods/*.md` files' own "Practitioner implementations" tables — per
D-07's locked instruction, competitors are pulled from what each doc already names, never
invented. `oris`/`raking`/`newton_kl` all attack the same K-margin box-bounded KL objective
`survey::calibrate`'s raking-calfun arm already measures on `medium_100k_5margins` (that arm
is reused, not recomputed — D-08's "narrow, not a duplicate study" framing). `greg` (chi-square
distance) and `logit` (logit distance) need their OWN `calfun=`-matched `survey::calibrate`
call, since pairing them against the raking-calfun arm would compare different objectives.

Purpose: close the "leafblower exposes 9 methods but the benchmark only covers 2" gap for the
5 methods reachable with zero new dependencies.
Output: `benchmarks/oris_soft_vs_competitors.R` extended with 7 new leafblower-only rows and 2
new distance-matched competitor rows on `medium_100k_5margins`; regenerated CSV/provenance.
</objective>
