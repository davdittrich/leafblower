<objective>
Close ROADMAP SC5: make the package's testthat edition match what its documentation claims,
via the fix-first-then-flip protocol.

Purpose: `CLAUDE.md` states the project runs testthat v3, but `DESCRIPTION` carries no
`Config/testthat/edition` field — and that field, not the `Suggests:` version bound, selects
the edition. The suite therefore runs edition 2, where `expect_equal` uses `all.equal`
tolerance semantics rather than waldo's stricter structural comparison. For a package whose
stated philosophy is absolute statistical correctness with `rtol=1e-6` parity gates, running
the laxer comparison engine while believing the strict one is active is a silent gap.

Output: `DESCRIPTION` opted into edition 3, with the deprecated constructs removed first in
their own commit.
</objective>
